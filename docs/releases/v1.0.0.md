# Token 余量 v1.0.0

首个公开版本。

## 主要功能

- 在 macOS 菜单栏显示 ChatGPT Weekly 剩余额度和自然重置倒计时。
- 显示可用额外 Reset 数量，并在临近到期时提醒。
- 每 60 秒自动刷新，支持立即刷新。
- 通过本机 ChatGPT/Codex app-server 复用登录状态，不保存登录令牌。
- 使用 `Token Balance Watcher` 随 ChatGPT 启动与退出。
- 提供 macOS 原生分层菜单和本机通知设置。

## 安装

1. 下载 `Token-Balance-macOS.zip`。
2. 解压并将 `Token Balance.app` 移入“应用程序”。系统显示名为“Token 余量”。
3. 当前构建为 arm64，要求 macOS 14 或更高版本。

## 签名说明

此版本使用 ad-hoc 签名，尚未经过 Apple Developer ID 公证。首次启动如被 Gatekeeper 阻止，请在 Finder 中右键应用并选择“打开”。
