# TokenBar macOS 菜单栏应用设计

## 目标

TokenBar 是一个常驻 macOS 菜单栏的订阅额度查看器。首个数据源为 ChatGPT 订阅额度，同时通过 Provider 接口为后续接入其他 AI 平台预留空间。

## 已确认的菜单栏表现

- 不显示环形进度图。
- 常态显示 `72% · W37 · 2d`：Weekly 剩余额度百分比、Weekly 剩余次数、距离自然重置的时间。
- 额外 Reset 临近过期时显示 `72% · W37 · R×1 8h`，用警示色替换自然重置倒计时区域。
- 点击菜单栏项目打开详情面板。

## 功能范围

详情面板显示当前 Provider、同步状态、Weekly 百分比、剩余次数、自然重置时间、可用额外 Reset 数量，以及每次 Reset 的过期时间。设置包括刷新频率、低额度阈值、Reset 到期提醒阈值、通知开关、登录/数据源入口和 Provider 选择。

第一版读取本机已登录的 ChatGPT 会话。凭证和会话数据只保存在本机，不上传到 TokenBar 自有服务。由于 ChatGPT 订阅数据没有面向第三方的稳定公开接口，采集器必须与领域模型隔离；当页面或接口变化时，只替换 ChatGPT Provider。

## 架构

- `UsageProvider`：统一数据源协议，暴露身份、授权状态和异步刷新方法。
- `ChatGPTProvider`：本机只读采集器。支持导入 ChatGPT 返回的 JSON 快照，并预留基于网页会话的采集适配器。
- `UsageSnapshot`：平台无关的额度快照，包含 Weekly、自然重置、额外 Reset 和采集时间。
- `UsageStore`：刷新调度、缓存、Provider 切换、错误状态和通知判断。
- `MenuBarLabel`：根据快照生成常态或提醒态紧凑文本。
- `NotificationCoordinator`：对低额度和 Reset 即将过期进行去重提醒。
- `SettingsStore`：使用 `UserDefaults` 保存非敏感偏好；敏感凭证应使用 Keychain。

实现语言采用 Objective-C/AppKit。原因是当前机器的 Swift 编译器与已安装 macOS SDK 版本不匹配且没有完整 Xcode；Objective-C 可使用同一 SDK 稳定生成原生菜单栏 `.app`，不改变产品架构或交互。

## 数据流

应用启动后加载缓存并立即展示最近快照，随后请求当前 Provider 刷新。刷新成功后原子更新缓存、菜单栏和详情面板，并计算通知；失败时保留最近成功数据，菜单栏标记为陈旧，详情显示错误和重试操作。定时器按用户设置继续刷新。

## 错误与隐私

- 无会话：显示“需要连接 ChatGPT”，不伪造额度。
- 上游字段缺失：字段显示 `—`；若只有百分比，不推算精确剩余次数。
- 上游结构变化：保留缓存并显示采集器需要更新。
- 网络不可用：指数退避，手动刷新始终可用。
- 所有采集和缓存均在本机进行；日志不记录 Cookie、令牌或完整响应。

## 测试与验收

- 菜单栏格式覆盖正常、低额度、Reset 到期、缺失字段和陈旧数据。
- JSON 解析覆盖完整/缺失/类型错误及未知字段。
- 通知去重和阈值边界有单元测试。
- Provider 可替换，测试 Provider 不依赖 ChatGPT。
- 生成可运行的 arm64 macOS `.app` 产物，并提供安装与数据接入说明。

## 非目标

第一版不修改或消费 Reset，不上传数据，不统计当前前台应用，不承诺绕过 ChatGPT 登录或反自动化机制，也不把估算值呈现为官方精确数据。
